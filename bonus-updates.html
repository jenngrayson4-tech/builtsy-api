Updating Any Site with Claude — Forever

This is the secret that makes your $30/month hosting retainer feel effortless. Every update a client ever needs — new photo, changed hours, added service, updated menu — takes 5 minutes. Here's exactly how.

The core idea

Your website is just a folder of files. Claude can read any file you upload and make any change you describe. That means Claude is your CMS, your developer, and your maintenance team — all in one.

No logging into WordPress. No broken plugins. No paying a developer $75/hour for a text change. Just upload the file, describe what you want, download the updated version, and redeploy.

📁
The File
Your HTML file is the database. Everything lives in it.
🤖
Claude
Your editor. Upload, describe the change, download.
🚀
Netlify
Your host. Drag the updated file, done in 30 seconds.

The exact workflow — every single time

  • 1Open a new Claude conversation. Don't use an old one — start fresh every time so Claude has clean context.
  • 2Upload the file that needs changing. Just the one file — not the whole folder. If the menu needs updating, upload menu.html. If the homepage needs a new photo, upload index.html.
  • 3Describe exactly what you want changed. Be specific. The more detail you give, the cleaner the result.
  • 4Claude returns the updated file. Copy the code into your file and save it. Or ask Claude to produce the full updated file as a download.
  • 5Drag the updated file to Netlify. Go to your site's Deploys tab, drag the updated folder. Live in 30 seconds.
That's literally it

Upload → describe → download → redeploy. Five minutes. Every update. Forever. This is why you can confidently charge $30/month for hosting — because each update costs you almost nothing in time.

How to ask Claude for changes

The way you describe the change matters. Here are the exact prompts that work best:

Simple text change

"Here's my restaurant website. Please update the hours to: Monday-Thursday 11am-9pm, Friday-Saturday 11am-11pm, Sunday 12pm-8pm. Keep everything else exactly the same."

Adding new content

"Here's my services page. Please add a new service called 'Deep Clean' with this description: [description]. Price is $250. Add it after the Regular Clean service. Match the exact styling of the existing service cards."

Updating a menu

"Here's my menu page. Please make these changes: Remove 'Tomato Soup' from the starters. Add 'Truffle Fries - $12' to the sides. Change the price of the Margherita Pizza from $14 to $16. Keep all formatting exactly the same."

Link in bio update

"Here's my link in bio page. Please add a new button for my TikTok — the URL is [url] and the label should be 'Follow on TikTok'. Add it as the second button, below Instagram. Match the style of the existing buttons exactly."

The magic phrase

"Keep everything else exactly the same."

Always end your request with this. It tells Claude not to redesign anything, just make the specific change you asked for.

Using this for your hosting clients

When you sell the $30/month hosting retainer, this is what you're actually selling — your time to manage updates using this system. Here's how to handle it professionally:

What to tell your hosting clients

"Any time you need a change — new photo, updated hours, new service added, price change, anything at all — just text or email me what you want. I'll have it live within 24 hours. That's included in your hosting."

Set a reasonable limit — "up to 5 small changes per month included, larger redesigns quoted separately." Most clients will use 1-2 updates per month maximum.

When a change is too big for one file

Sometimes a client wants a bigger change — a whole new page, a redesign of a section, a new feature added. For those:

  • 1Upload all relevant files — if it affects multiple pages, upload all of them at once
  • 2Describe the full scope — "I need to add a new Gallery page and link it from the navigation on every page"
  • 3Let Claude work through it file by file — same as the original build process
  • 4Quote appropriately — a new page is a bigger job, charge $50-100 on top of the retainer
The client doesn't need to know any of this

From your client's perspective you're a professional who handles all their website updates quickly and reliably. The fact that you use Claude to do it in 5 minutes is your business — not theirs. This is your system. Own it.
